# Telos v0.11 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the specification, replay, generated integrations, CI, documentation, and demo recording pipeline consistently target Telos v0.11.0.

**Architecture:** Preserve the current final model as the compatibility oracle while rewriting the cumulative replay so v0.11 constructs that model through owned contexts and capabilities. Refresh exact generated assets and version pins, replace the recorder's old navigation with semantic v0.11 feature checkpoints, then reseal and prove the replayed repository matches the checked-in state byte-for-byte.

**Tech Stack:** Telos CLI 0.11.0, Python 3.12+, unittest, pytest, Playwright Chromium, FFmpeg, Markdown replay directives, GitHub Actions YAML.

**Spec:** `docs/superpowers/specs/2026-08-25-telos-v0.11-migration-design.md`

## Global Constraints

- v0.11.0 is the one exact active install pin and generated-state tool version;
  migration documentation may name superseded versions only to explain their removal.
- Preserve all application behavior, 12 intent IDs, 17 scenario IDs, two constraints, and tags `v0.0.0` through `v0.5.0`.
- Never edit specification files under `telos/` manually; reseal only through `telos change reconcile --full --json`.
- Preserve the configured Claude-only agent host; do not add Codex integration.
- The clean replay must use the public CLI only and finish with `--compare` passing.
- The upgraded tour must cover global search, canonical intent/scenario content, graph finder/focus, and glossary consumers.
- The generated GIF remains 960 pixels wide, 10 fps, full-palette, and strictly below 10 MB.
- Every shell command in this repository is prefixed with `rtk`.

## File Structure

- `prompts/00-bootstrap.md`: v0.11 bootstrap, generated integration, and initial state.
- `prompts/01-hatch-and-feed.md`: creation of the pet context/capabilities and first owned entities.
- `prompts/02-play-and-mood.md` through `prompts/05-evolution-and-cli.md`: owned edits/additions, terminal projection, context map, witnesses, and final full reseal.
- `prompts/06-the-drift-incident.md`, `prompts/07-your-turn.md`: qualified v0.11 paths and selectors.
- `README.md`: one v0.11 install/replay story.
- `.github/workflows/demo.yml`, `.github/workflows/demo-gif.yml`, `.github/workflows/telos.yml`: checksum-verified v0.11 installers and replay comparison.
- `.claude/skills/*/SKILL.md`: exact assets embedded in upstream tag v0.11.0.
- `tools/record_demo.py`: semantic v0.11 tour, trace result, blue/cyan cursor, and encoding pipeline.
- `tools/test_record_demo.py`: browser-tour contract and existing GIF encoding contracts.
- `docs/demo.gif`: generated v0.11 tour.
- `telos/telos.lock`: CLI-generated v0.11 seal.
